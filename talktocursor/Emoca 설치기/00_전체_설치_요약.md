## 사전 준비

### 1. 디스크 공간 확인
- `/home` 디스크 공간 확인 (최소 15GB 권장)
- 부족하면 conda 캐시 정리: `conda clean --all`

### 2. Conda 설정
`~/.condarc` 파일 설정:
```yaml
solver: libmamba
channel_priority: flexible
pkgs_dirs:
  - /media/cine/First/HWPJ2/Temp/conda_pkgs
```

### 3. 환경 변수 설정
```bash
# Temp 폴더가 비어있어도 자동으로 생성됨
export CONDA_PKGS_DIRS=/media/cine/First/HWPJ2/Temp/conda_pkgs
export TMPDIR=/media/cine/First/HWPJ2/Temp
export TEMP=/media/cine/First/HWPJ2/Temp
export PIP_CACHE_DIR=/media/cine/First/HWPJ2/Temp/pip_cache
```

**참고:** Temp 폴더가 비어있어도 설치 중 자동으로 생성됩니다.

### 3단계: PyTorch 설치
```bash
conda activate work38_cu11
conda install -y pytorch==1.12.1 torchvision==0.13.1 torchaudio==0.12.1 cudatoolkit=11.3 -c pytorch
```
**상세**: `03_PyTorch_설치.md`

---

### 4단계: pip 및 기본 패키지 설치
```bash
conda activate work38_cu11

# pip 다운그레이드
pip install pip==24.0

# Cython 설치
pip install Cython==0.29.14

# requirements38.txt 설치
pip install -r requirements38.txt

# 호환성 패키지 수정
pip install --force-reinstall protobuf==3.20.3
pip install --force-reinstall numpy==1.23.5
```
**상세**: `04_pip_및_기본패키지_설치.md`

---

### 5단계: PyTorch3D 설치
```bash
conda activate work38_cu11

# 의존성 설치
pip install fvcore iopath

# PyTorch3D 0.7.2 precompiled wheel 설치
pip install --no-index --no-cache-dir pytorch3d==0.7.2 \
    -f https://dl.fbaipublicfiles.com/pytorch3d/packaging/wheels/py38_cu113_pyt1121/download.html
```
**상세**: `06_PyTorch3D_설치.md`

---

### 6단계: mediapipe 설치
```bash
conda activate work38_cu11

# OpenCV 충돌 해결
pip uninstall -y opencv-contrib-python opencv-python-headless

# mediapipe 설치
pip install mediapipe==0.10.5

# kiwisolver 문제 해결
pip uninstall -y matplotlib kiwisolver
conda install -y matplotlib kiwisolver -c conda-forge
export LD_LIBRARY_PATH=$CONDA_PREFIX/lib:$LD_LIBRARY_PATH
```
**상세**: `07_mediapipe_설치.md`, `07-1_mediapipe_문제해결.md`
