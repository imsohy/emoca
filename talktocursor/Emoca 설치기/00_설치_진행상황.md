```bash
export LD_LIBRARY_PATH=$CONDA_PREFIX/lib:$LD_LIBRARY_PATH
```

또는 영구 설정:
```bash
mkdir -p $CONDA_PREFIX/etc/conda/activate.d
echo 'export LD_LIBRARY_PATH=$CONDA_PREFIX/lib:$LD_LIBRARY_PATH' >> $CONDA_PREFIX/etc/conda/activate.d/env_vars.sh
```

## 문제 해결 기록

### 문제 1: face_detection LFS 파일
- **상태**: Git LFS 포인터 파일만 존재 (실제 파일 없음)
- **해결**: 실제로는 사용되지 않는 것으로 확인, 진행 가능

### 문제 2: /home 디스크 공간 부족
- **상태**: /home 디스크 100% 사용 중
- **해결**: conda 캐시 정리 및 설정 변경

### 문제 3: mediapipe kiwisolver GLIBCXX 문제
- **상태**: 시스템 libstdc++ 버전이 낮음
- **해결**: conda로 재설치 및 LD_LIBRARY_PATH 설정

### 문제 4: numpy.object 오류
- **상태**: numpy 1.24.4에서 np.object가 제거됨
- **해결**: numpy 1.23.5로 다운그레이드

### 문제 5: psutil getpagesize 오류
- **상태**: 바이너리 wheel이 현재 시스템과 호환되지 않음
- **해결**: psutil을 소스에서 재컴파일

### 문제 6: OpenCV INTER_NEAREST 오류
- **상태**: OpenCV가 제대로 설치되지 않음
- **해결**: OpenCV 재설치
